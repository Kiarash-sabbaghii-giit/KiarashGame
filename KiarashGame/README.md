## 💜 About the Project

**KIARASH GAME** is a web-based gaming platform built with **Django** that brings together 20 original Python-powered arcade games in one futuristic neon universe.

Designed with a cyberpunk and synthwave aesthetic, the platform lets users create accounts, discover games, preview gameplay through animated demos, and launch their favorite experiences directly from the web interface.

Every game is designed to deliver a polished arcade experience featuring neon visuals, procedural sound, achievements, score tracking, and engaging gameplay mechanics.

### ✨ Key Highlights

- 🎮 **20 original arcade games** built with Python and Pygame.
- 🌈 Futuristic neon, cyberpunk, and synthwave visual identity.
- ⚡ Interactive web platform powered by Django.
- 🏆 Score tracking and achievement-focused gameplay.
- 👾 Animated GIF previews for every game.
- 🚀 One-click game launching from the web interface.
- 💾 Persistent user and game data with SQLite.
- 📱 Responsive design for desktop and mobile devices.

## ⚡ Features

- 🔐 **User Authentication** — Signup, login, and logout functionality.
- 👤 **User Profiles** — View personal information and play history.
- 🔎 **Game Search** — Quickly find games through the search bar.
- 🎮 **Game Detail Pages** — Explore descriptions, previews, and game information.
- 🎞️ **Animated Demo GIFs** — Preview gameplay before launching a game.
- 🚀 **One-Click Game Launch** — Start games directly from the platform.
- 🔢 **Play Counter** — Track how many times each game has been played.
- 🌌 **Neon Cyberpunk UI** — Futuristic visuals with RGB animations.
- 📱 **Responsive Design** — Optimized for different screen sizes.
- 🗄️ **SQLite Persistence** — Store users, games, and platform data.
- 📂 **Django Static & Media Management** — Organize assets and uploaded media.
- 🔊 **Procedural Sound** — Dynamic audio experiences across the games.
- 🏆 **Achievements** — Reward players for reaching gameplay milestones.
- 💫 **Polished Game Interfaces** — Consistent visual language across the arcade.

## ⚡ Installation

### 1. Clone the Repository

~~~bash
git clone https://github.com/KIARASH/KIARASH-GAME.git
cd KIARASH-GAME
~~~

### 2. Create a Virtual Environment

#### Windows

~~~bash
python -m venv venv
venv\Scripts\activate
~~~

#### Linux / macOS

~~~bash
python3 -m venv venv
source venv/bin/activate
~~~

### 3. Install Dependencies

~~~bash
pip install -r requirements.txt
~~~

### 4. Apply Database Migrations

~~~bash
python manage.py makemigrations
python manage.py migrate
~~~

### 5. Create a Superuser

~~~bash
python manage.py createsuperuser
~~~

### 6. Collect Static Files

~~~bash
python manage.py collectstatic
~~~

### 7. Run the Development Server

~~~bash
python manage.py runserver
~~~

Open the platform in your browser:

~~~text
http://127.0.0.1:8000/
~~~

## 🔐 Environment Variables

For production environments, configure sensitive settings using environment variables.

Example:

~~~text
SECRET_KEY=your-secret-key
DEBUG=False
ALLOWED_HOSTS=localhost,127.0.0.1
DATABASE_URL=your-database-url
~~~

Never commit real secrets, passwords, or private credentials to the repository.
